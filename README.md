One original funny line about a houseplant and the self-watering pot that was supposed to save it: the plant still died, only now it drowns on a schedule. `main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–200 UTF-8 characters and verifies the written file round-trips exactly.
